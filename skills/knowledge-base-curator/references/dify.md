# Dify 适配

按任务查阅当前官方文档：
- 知识检索：https://docs.dify.ai/en/cloud/use-dify/nodes/knowledge-retrieval
- 知识库与流水线入口：https://docs.dify.ai/

平台界面和插件可变化，不把本文件当固定版本的点击教程。

## 文本与范围

- Markdown 卡片中的角色标签不自动创建 Dify 文档元数据。实际配置 manual_scope 等字段，并验证检索节点过滤使用了正确值。
- 角色过滤用于内容匹配，不能替代应用后端的用户权限校验。
- 按操作卡标题或 `\n---\n` 等完整边界尝试分段；通过预览确认标题、范围、操作、限制、图片没有散开。不要把单行文字或图片 URL 单独当答案片段。
- 系统用父子分段时，子段也需要足够任务语义；是否用通用分段要通过对照测试决定。

## 多模态

官方知识检索说明：含图检索结果可在 result 中带 files；视觉 LLM 可使用这些检索图片。文本 Markdown 的外链是否会被解析为真实图片，取决于所用流水线与提取器，必须验证。

多模态检索若选用了只支持文字的重排模型，可能将图片排除。采用平台当前支持的多模态重排，或在适合的场景关闭该环节并验证结果；不要因此统一改掉文字库的重排设置。

图片类型、大小、数量限制按当前官方文档和实际节点确认，不在本 Skill 固化为所有系统的常量。

附件类型报错、全局上传开关、模型权限等属于工作流配置问题。内容清洗和工作流修复分别验证。未经实际导入运行，交付说明写明未执行线上验收。
